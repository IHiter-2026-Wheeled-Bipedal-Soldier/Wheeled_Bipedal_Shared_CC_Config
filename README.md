推荐工作流程写在 Resources/AI辅助嵌入式开发工作流系统.md 里面。
整个工作流采用解耦方式构建，不强制按照整个工作流执行，可以单独使用工作流中的各项技能。
强制采用git进行自动管理，保证AI写的代码可随时回退。
采用自迭代记忆逻辑构建，会自动记忆处理过程中遇见的错误，防止下次犯同样的错误。
